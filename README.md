# Scanner de acciones del mercado (NO ES RECOMENDACION DE INVERSIÓN).

Escanea bajo parametros de análisis técnico: Indice de fuerza relativa y MACD. Busca la tendencia a largo plazo alcista mientras que bajamos de temporalidad para afinar el timing de entrada al activo. Dicha estrategia esta inspirada en la triple pantalla de Dr. Elder Alexander, extraida de su libro El Nuevo Vivir del Trading. 

Permite captar movimientos de mercado de forma automatizada, este script ahorra horas de trabajo frente al analisis de activos uno por uno, proporciona de un plumazo los activos de interes para nuestras estrategias de trading.
